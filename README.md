Space Invaders Game

This is a classic Space Invaders–style arcade game built using Python and Pygame. The player controls a small spaceship positioned at the bottom of the screen and must shoot down approaching enemies before they reach the player’s area. Each enemy destroyed increases the score, while missing too many can lead to a game over.

The game features smooth player movement, bullet firing mechanics, enemy waves with random positions, collision detection, and a simple scoring system — all created with clean and beginner-friendly Python code.
